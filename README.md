# Stern SP Website

Repository for the Stern SP Website. This project is built as a modern Nx workspace using TypeScript and Angular.

## Features

- **Nx Workspace:** Utilize Nx for powerful monorepo support, advanced build and test commands, and code generation.
- **Angular Frontend:** The main application is built with Angular, leveraging Nx plugins to simplify project creation and management.
- **TypeScript:** All code is written in TypeScript for type safety and modern development practices.
- **Testing:** Integrated with Jest for unit testing and Playwright for end-to-end testing.
- **Linting:** ESLint is set up for both TypeScript and Angular templates, following best practices.
- **CI/CD Ready:** Nx Cloud integration available to speed up and cache CI workflows.

## Getting Started

### Prerequisites

- Node.js
- npm

## Project Structure

- `Frontend/`: Main Angular app and related configuration.
- `Frontend/src/`: App source files.
- `Frontend/e2e/`: End-to-end tests with Playwright.
- `Frontend/jest.config.ts`: Jest configuration for unit tests.
- `Frontend/eslint.config.mjs`: ESLint configuration.
